# casual-hebrew-public

The public website for **Casual Hebrew**, served by GitHub Pages:
https://dlebee.github.io/casual-hebrew-public/

- `/` landing page
- `/privacy/` privacy policy (use this URL in App Store Connect and Google Play)
- `/support/` support page

Plain HTML and CSS, no build step. The app's source lives in a separate private repo.
Bug reports and translation fixes are welcome as issues here.

Built by David Lebee.
